# VISION
To build an unrestricted, highly customized AI companion web application featuring a real-time, interactive 3D character with audio-driven lip-sync, procedural animations, dynamic environment responsiveness, and uncensored AI orchestration via open-weight models.

## Core Pillars
1. **Interactive 3D Avatar (Pixiv VRM & Three.js)**: High fidelity, responsive skeletal animations, real-time mouse look-at tracking, procedural blinking, and blendshape facial expressions.
2. **Audio & Voice Immersion**: Triple-tier text-to-speech architecture supporting native browser SpeechSynthesis, ElevenLabs neural voice streaming, and Kokoro WebGPU local in-browser neural synthesis with dynamic FFT viseme lip-sync.
3. **Consolidated Studio Dashboard**: Single-page, zero-fragmentation control panel organizing AI persona configuration, voice settings, lighting/environment selection, camera presets, and session controls with rich tooltip guidance.
4. **Resilient Architecture**: Client-heavy, server-light paradigm with Prisma/SQLite persistence, JWT session isolation, input sanitization, and automated server lifecycle controls.
